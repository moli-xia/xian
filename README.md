# 仙 (Xian)

一个基于 **TypeScript**、**Vite** 和 **Three.js** 构建的浏览器 3D 仙侠竞技场游戏。  
玩家将驾驭飞行法器，在云雾缭绕的修仙战场中收集灵力水晶、强化刀阵、释放法术，并击败场上全部敌修，完成一场属于自己的“渡劫之战”。

## 项目简介

本项目以“修仙竞技场”为核心概念，将仙侠题材、即时战斗、资源争夺和成长机制结合在一起。  
游戏采用第三人称俯视角表现，强调以下体验：

- 在场景中高速移动、抢夺灵力水晶与技能水晶
- 通过不断强化护体法器数量来提升正面对抗能力
- 在敌我交锋时，通过走位、冲刺和法术改变战局
- 在多名敌修与复杂场景中完成清场，最终获得胜利

## 游戏玩法

### 胜利目标

- 击败竞技场中的全部敌修即可获胜
- 玩家被击溃时游戏结束
- 结算界面会显示本局击败数与最终灵力值

### 核心循环

一局游戏的主要流程如下：

1. 进入战场并输入自己的道号
2. 在场地中移动，优先抢夺附近水晶
3. 通过灵力成长提升法器数量、移动能力和技能储备
4. 利用冲刺、闪电和气墙寻找开团或反打机会
5. 逐个击败敌修，并吸收对方剩余的部分成长收益
6. 清空场上所有敌人，完成“渡劫成功”

### 战斗规则

游戏的战斗并不是单纯的数值互砍，而是围绕“护体法器”展开：

- 每名修士身边都会环绕法器，法器越多，整体压制力越强
- 法器之间发生碰撞时，弱势一方会损失更多法器并受到震退、眩晕或伤害
- 法器直接刮到目标本体时，也会造成持续压迫和生命值削减
- 优势方在对拼中还能获得短时间移速收益与生命回复
- 击败敌人后，胜者会吸收一部分对方的成长收益与技能储备

这让战斗同时具备：

- 资源争夺的滚雪球感
- 近距离对拼的碰撞反馈
- 技能切入与反打的策略空间

## 操作说明

### 基础操作

- `W A S D` 或方向键：移动角色
- 鼠标左键：释放当前选中的技能
- 鼠标右键：切换当前技能
- `Esc`：暂停 / 继续游戏
- `R`：在结算后重新开始
- `Enter`：在开始界面快速进入游戏

### 战斗建议

- 开局优先抢法器与移速类水晶，尽快建立滚雪球优势
- 当法器数量落后时，尽量避免正面对撞，优先绕场发育
- 技能水晶很关键，尤其适合在中后期逆转战局
- 冲刺适合切后排、追击残血或脱离危险区域
- 气墙可用于打断追击路线、制造地形分割

## 成长与资源系统

游戏中的成长主要来自场景中不断刷新的水晶球。部分水晶由场上的灵兽吐出，部分会持续在地图中刷新。

### 水晶类型

- `器`：增加 1 片护体法器，是最核心的成长资源
- `速`：提供移速增益，适合抢图、拉扯和追击
- `愈`：恢复生命值，帮助玩家续航
- `雷`：增加 1 次闪电技能使用次数
- `冲`：增加 1 次冲刺技能使用次数
- `墙`：增加 1 次气墙技能使用次数

### 成长表现

随着成长推进，角色会逐步获得以下变化：

- 灵力值提升
- 环绕法器数量增加
- 对拼强度增强
- 机动性更高
- 可用技能次数增加

## 技能系统

游戏中存在 3 种主动技能。玩家拾取对应技能水晶后即可解锁，并通过鼠标右键切换当前技能。

### 闪电

- 对目标区域释放雷击
- 可优先命中范围内的多个目标
- 能造成直接伤害
- 可打断敌人节奏并削减目标法器数量

适用场景：

- 开团先手
- 追击正在逃跑的敌修
- 群战中压制多个目标

### 冲刺

- 朝目标方向进行高速突进
- 在突进过程中对碰撞到的目标造成伤害和强力击退
- 适合快速切入、追击、脱战或抢资源

适用场景：

- 快速收掉残血
- 从劣势位置强行脱身
- 穿越混战区制造节奏差

### 气墙

- 在目标位置生成短时间存在的灵气屏障
- 可充当地形阻挡，干扰追击与走位
- 适合切割战场和保护自身

适用场景：

- 被追击时封路
- 逼迫敌人绕行
- 在狭窄区域制造站位优势

## 场景与特色

### 仙侠竞技场氛围

项目围绕“修仙竞技场”主题构建了完整的视觉氛围：

- 角色使用仙侠人物模型
- 玩家与敌修拥有不同名称与配色风格
- 战场中有云雾、灵光、火花、法阵、泛光等仙气效果
- 护体法器、闪电、冲刺轨迹和气墙都有明显的法术表现

### 灵兽与地图互动

除玩家与敌修外，场景中还存在四处游走的灵兽：

- 灵猫、灵狗等灵兽会在战场中随机移动
- 灵兽会成为水晶生成的重要来源之一
- 它们会主动远离修士，让战场更具动态变化

地图中还包含额外交互要素：

- 四角传送阵，可将角色快速转移到其他区域
- 障碍物与场景模型，会影响走位和追击路线
- 浮空云台 / 飞剑载具表现，强化修仙主题辨识度

## 游戏特色

### 1. 仙侠题材与竞技对抗结合

不是传统回合制修仙，也不是纯叙事体验，而是将仙侠世界观与实时竞技场战斗融合，形成更直接、更爽快的交互节奏。

### 2. 以“法器刀阵”为核心的战斗设计

法器数量既是成长指标，也是实际战斗单位。  
玩家获得的不只是抽象属性，而是能够直观看见、直接参与碰撞与输出的“护体刀阵”。

### 3. 轻成长 + 强反馈

每次拾取、碰撞、击退、雷击和斩杀都有明确反馈，战斗节奏快，成长结果可见，适合短局反复游玩。

### 4. 多系统同时作用

本项目不是单一战斗演示，而是融合了：

- 角色移动
- AI 敌人行为
- 技能释放
- 水晶刷新与吸附
- 传送阵
- 障碍碰撞
- 音效与 UI 提示

因此整体体验更接近一个完整可玩的原型，而不是单纯的 3D 场景展示。

## 技术实现亮点

- 使用 **Three.js** 构建 3D 场景、角色、特效与交互
- 使用 **EffectComposer** 与 **UnrealBloomPass** 实现后处理泛光效果
- 使用 **FBXLoader** 与 **GLTFLoader** 加载角色、灵兽与场景模型
- 使用 **TypeScript** 组织角色状态、技能系统、UI 与战斗逻辑
- 使用浏览器原生音频能力实现 BGM 与音效控制
- 提供开始界面、HUD、技能栏、暂停界面和结算界面


## 本地运行

### 环境要求

- Node.js 18 及以上版本
- npm 9 及以上版本

### 安装依赖

```bash
npm install
```

### 启动开发环境

```bash
npm run dev
```

启动后根据终端提示在浏览器中打开本地地址即可体验游戏。

### 构建生产版本

```bash
npm run build
```

### 预览构建结果

```bash
npm run preview
```
